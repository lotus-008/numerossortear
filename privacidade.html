Política de Privacidade

Última atualização: 27 de maio de 2026

1. Quem somos

O numerossortear.com é um site de ferramentas gratuitas de aleatoriedade — gerador de números aleatórios, chaves de lotaria, dados, moedas e senhas. Todas as operações são executadas diretamente no teu browser, sem envio de dados para servidores.

2. Dados que recolhemos

Este site não recolhe dados pessoais identificáveis diretamente. No entanto, alguns serviços de terceiros integrados podem recolher dados automaticamente:

  • Anúncios — podem recolher dados de navegação e definir cookies para mostrar anúncios relevantes.
  • Google Analytics — recolhe dados anónimos de utilização (páginas visitadas, tempo no site, país, dispositivo) para fins estatísticos.

Nenhum destes dados é vendido ou partilhado com terceiros além dos próprios serviços indicados.

3. Cookies

Utilizamos cookies para os seguintes fins:

  • Cookies de publicidade — usados para mostrar anúncios com base nos teus interesses.
  • Cookies de análise — usados para entender como os visitantes utilizam o site.

Ao entrares no site pela primeira vez, ser-te-á apresentado um banner de consentimento onde podes aceitar, recusar ou gerir as tuas preferências de cookies. Podes também gerir ou eliminar cookies a qualquer momento nas definições do teu browser.

4. Publicidade

Este site exibe anúncios para se manter gratuito. Esses anúncios podem usar cookies para mostrar conteúdo baseado nas tuas visitas anteriores a este e a outros sites.

Podes gerir as tuas preferências de publicidade personalizada nas definições do teu browser ou através das opções de privacidade disponíveis nos serviços de anúncios.

5. Os teus direitos (RGPD)

Ao abrigo do Regulamento Geral de Proteção de Dados (RGPD), tens os seguintes direitos:

  • Direito de acesso aos teus dados pessoais
  • Direito de retificação de dados incorretos
  • Direito ao apagamento dos teus dados
  • Direito de oposição ao tratamento dos teus dados
  • Direito de retirar o consentimento a qualquer momento

Para exercer qualquer um destes direitos, contacta-nos através do email indicado abaixo.

6. Alterações a esta política

Podemos atualizar esta Política de Privacidade ocasionalmente. Quaisquer alterações serão publicadas nesta página com a data de atualização. Recomendamos que a consultes periodicamente.
